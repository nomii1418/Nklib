## 🆘 Troubleshooting

### Backend won't start:
```
→ Check Render logs
→ Verify MongoDB URL
→ Check all env vars
→ Test MongoDB connection
```

### Frontend can't connect:
```
→ Check VITE_API_URL
→ Should point to backend
→ Redeploy after changing
```

### Bot not responding:
```
→ Check bot worker logs
→ Verify bot token
→ Check BACKEND_URL
→ Test with @BotFather
```
