1️⃣  MONGODB ATLAS CONNECTION STRING

Where: https://mongodb.com/cloud/atlas/register
Time: 2 minutes
Cost: FREE forever

Steps:
  a) Sign up (use Google login - fastest)
  b) Create FREE M0 cluster
  c) Create database user:
     - Username: admin
     - Password: (create secure one, SAVE IT!)
  d) Network Access: Add 0.0.0.0/0 (allow all)
  e) Get connection string:
  
     mongodb+srv://admin:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/mechanical_library
     
     ⚠️  Replace YOUR_PASSWORD with your actual password!

Example:
mongodb+srv://admin:MyPass123@cluster0.abc.mongodb.net/mechanical_library

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣  TELEGRAM BOT TOKEN

Where: @BotFather on Telegram
Time: 1 minute
Cost: FREE

Steps:
  a) Open Telegram
  b) Search: @BotFather
  c) Send: /newbot
  d) Name: Mechanical Library (or any name)
  e) Username: nklib_mechanical_bot (must end with _bot)
  f) Copy token BotFather gives you

Example:
7364728191:AAGvH5xKz8pQwE_RtF2...
